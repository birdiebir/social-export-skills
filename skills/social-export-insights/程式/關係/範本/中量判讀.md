# 質性分析任務說明（中層：事件時間軸／精選語錄／語氣序列）

你正在協助分析一段私人 Facebook Messenger 對話，雙方是**{{SELF_LABEL}}**（訊息
擁有者本人）與**{{OTHER_NAME}}**。這是「重要聯絡人關係分析」pipeline 的中層加值
任務——不是重新判讀整段關係，而是在**既有的**逐季或全歷程敘事筆記
（`notes/{{SLUG}}/note.md`，可能是深季判讀或輕量判讀產出的版本）之上，補三份結
構化產出：事件時間軸、精選逐字語錄、語氣起伏序列。

## 為什麼要做這個（不是重複勞動）

既有的 `note.md` 是散文敘事，人要一段一段讀才知道發生過什麼；這個任務把敘事裡
「重大事件或轉折」條列的內容抽成可視覺化的時間軸，把敘事裡提到但沒有原文的片
段換成真正的逐字語錄，並把每季的「關係基調」量化成一條可畫圖的語氣序列——三者
合起來讓 dashboard 使用者不用整篇讀完就能抓到重點，也能一眼看出語氣的長期趨勢。

## 你的任務

1. **讀完 `notes/{{SLUG}}/note.md` 全部季度段落**（或全歷程摘要，若這位對象是
   輕量判讀產出的單篇版本），逐季（或整段）抓出「重大事件或轉折」條列的內容。
2. **讀 `notes/{{SLUG}}/excerpts/*.md`**（逐字原文摘錄），從中挑選 15～25 則精
   選語錄（好笑／經典／溫馨／轉折點皆可，數量依實際內容多寡調整，訊息量小的
   對象不必湊數）。`quote` 欄位**必須是複製貼上的逐字原文**，不可意譯、不可
   用「……」截斷長訊息、不可把兩則相鄰但獨立的訊息拼接成一則——這三種是最容
   易出現、也最容易被人工抽查漏掉的錯誤（見 `分析\踩坑.md` 第 16 條）。
3. 寫出 `notes/{{SLUG}}/timeline.json`：每季（或每個顯著時期）一筆，`headline`
   從該季條列內容濃縮成一句話，不得新增筆記裡沒有提到的事件：
   ```json
   [{"quarter": "2018Q2", "date_range": ["2018-04-01", "2018-06-30"],
     "headline": "一句話事件標題", "anchor": "q-2018Q2"}]
   ```
   `anchor` 格式固定 `q-<quarter>`，對應合併頁面裡該季落地的錨點 id。若這位對
   象的 `note.md` 沒有逐季分段（只有一整篇敘事），改成依 `note.md` 裡「顯著時
   期或事件」條列內容拆成對應時期的筆數，`anchor` 一樣指到（唯一存在的）敘事
   區塊，見「已知落差」一節。
4. 寫出 `notes/{{SLUG}}/quotes.json`：
   ```json
   [{"timestamp": "2018-06-15T21:28:10", "speaker": "顯示名稱",
     "quote": "逐字原文（一字不改）", "context": "前後脈絡一到兩句話說明",
     "reason": "好笑|經典|轉折點|溫馨|其他"}]
   ```
   `context` 欄位可以自己摘寫，但 `quote` 欄位本身要能通過下一步的逐字驗證。
5. 依固定五類量表為每一季（或每個顯著時期）評語氣分類，寫出
   `notes/{{SLUG}}/sentiment.json`：
   ```json
   [{"quarter": "2018Q2", "label": "positive_warm",
     "rationale": "一句話說明依據", "confidence": "medium"}]
   ```
   五類固定為 `positive_warm`（正向熱絡）／`steady_routine`（平穩日常）／
   `low_distant`（低頻疏遠）／`tense_conflict`（緊張衝突）／`complex_mixed`
   （複雜矛盾，同一季同時有明顯正向與負向訊號時用這個，不要硬選一邊）。
   `rationale` 必須具體引用該季敘事或原文語氣線索（標點、表情符號、用詞），
   不要寫空泛的套話；`confidence` 是 `low`/`medium`/`high`。這是 LLM 輔助分
   類，不是臨床心理量表，合併頁面呈現時要附這句方法說明。
6. **跑驗證，不通過就修正對應那一筆再重跑，不是整份重寫**：
   ```bash
   python 程式/共用/verify_quotes_template.py \
     --quotes notes/{{SLUG}}/quotes.json \
     --excerpts-dir notes/{{SLUG}}/excerpts
   ```
   必須 `[PASS]`。

## 已知落差（資料本身粒度不足時的降級處理，不是偷工）

- 若 `note.md` 沒有逐季 `<h2>` 小節（只有一篇整體敘事＋人物側寫），`timeline.json`
  的 `anchor` 沒有對應的季度標題可以連——在合併頁組裝時（不是這個任務的範圍），
  會在敘事區塊頂端插入不可見的 `<span id="q-<quarter>">` 佔位錨點，讓連結至少
  跳到唯一存在的那段敘事，而非死連結。你只需要照常在 `timeline.json` 裡填正
  確的 `anchor` 值，不用自己處理 HTML。
- 若這位對象沒有既有的 `quant/{{SLUG}}/report.html`（量化圖表頁不存在），那是
  合併頁組裝階段的事，不影響你這個任務的三份 JSON 產出。

## 誠實原則

這是私人真實對話，內容可能包含敏感或私密話題，請以中立、不帶評判的分析角度
處理。事件與語氣判讀都要基於實際讀到的內容，不要為了故事性或版面豐富度誇大、
編造，或為了湊數量硬選不夠格的語錄。
