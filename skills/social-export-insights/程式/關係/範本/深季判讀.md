## 你的任務
1. 用 Read 工具依序讀取 `excerpts/` 底下每一季的摘錄檔（.md，格式為每天一個
   區塊，`- HH:MM 姓名: 內容`）。
2. 注意：非「統計異常月」的部分是代表性抽樣（不是完整逐字稿），「統計異常月」
   則是重點加密收錄；抽樣不代表當月只發生抽樣到的事，但已盡量涵蓋分散的日期。
3. 每一季判讀後，輸出以下固定格式的 Markdown 區塊（依時間順序，一季一個）：

```
## {quarter}
**關係基調**：（2-4 句，這一季整體感覺是熱絡/疏離/緊張/穩定/甜蜜…，以及為什麼）
**重大事件或轉折**：
- （條列，若無明顯事件可寫「無明顯特殊事件，屬於平穩期」）
**{{SELF_LABEL}}溝通風格觀察**：（這一季展現出的性格/溝通傾向，例如主動性、情緒表達方式、幽默感、耐心程度等，須基於你實際讀到的內容，不要空泛套話）
**{{OTHER_NAME}}溝通風格觀察**：（同上）
**與統計趨勢的對照**：（若這一季有被標記的「統計異常月」，試著用你讀到的內容解釋為什麼那個月的指標會偏離趨勢線；若沒有異常月，可略述本季內容是否符合整體長期趨勢）
**代表性片段**：
> YYYY-MM-DD HH:MM 姓名: 原文片段（挑 2-4 則最能代表這一季基調的對話，可簡短，保留原文語氣）
```

4. 全部季度讀完後，在最前面依序加上：
   - YAML frontmatter（欄位規範見 `筆記格式.md`，由呼叫端提供
     的既有資料填入，不用自己重新計算）
   - `**一句話摘要**：`（單句，供 dashboard 卡片顯示，扼要描述這段關係的性質）
   - `**關係總覽**：`（3-5 句，整段關係從頭到尾的整體樣貌，跨季總結）

5. 誠實判讀，不要為了故事性而誇大或編造內容中沒有的情緒/事件。如果某季內容
   平淡或多為生活瑣事、通話記錄、系統訊息，就如實反映「平淡/低互動」，不要硬
   掰出戲劇性轉折。
6. 這是私人真實對話，內容可能包含敏感或私密話題（金錢、感情摩擦、家庭等），
   請以中立、不帶評判的分析角度處理，不要對任何一方做道德評價。
7. 只輸出最終的 note.md 完整內容（frontmatter ＋ 一句話摘要 ＋ 關係總覽 ＋ 逐
   季區塊），不要有其他前言或結尾語。
