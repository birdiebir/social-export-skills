# 質性分析任務說明（人物側寫彙整，深化既有筆記，非新讀原始訊息）

你正在協助把一份已經完成的「重要聯絡人關係筆記」，補上一段獨立的「人物側寫」
——描述**{{OTHER_NAME}}**這個人整體是什麼樣的人，而不是這段關係本身的性質。

這是二次彙整既有素材，**不需要、也不應該重新讀原始訊息全文**（`messages_full.jsonl`
或該對象的完整聊天記錄）——所有素材都已經備妥：

## 你的任務

1. 用 Read 工具讀取 `quant/<person_slug>/persona_evidence.json`，裡面有：
   - `quant_summary`：對方的溝通風格量化平均值（`question_rate`／`exclaim_rate`／
     `ellipsis_rate`／`media_rate`／`unsent_rate`／`latenight_rate`／
     `sentiment_mean`／`sentiment_std`／`response_latency_min`，皆為 0~1 的比率
     或原始量測值）、`dominant_initiator`（"self" 或 "other"，誰比較常主動開啟
     話題）。
   - `top_keywords`：這段對話最常出現的主題詞（jieba 斷詞結果，**已過濾常見停用詞
     但仍可能殘留斷詞雜訊或語意不完整的片段**，例如時間詞、殘缺詞——請自行判斷
     哪些真的反映話題/興趣，哪些是雜訊，雜訊不要寫進側寫裡）。
   - 深層（tier=deep）：`trait_observations`——逐季累積的「{{OTHER_NAME}} 溝通風格
     觀察」句子列表，是這個人過去質性分析時已經寫下的性格觀察，直接整合改寫即可。
   - 輕層（tier=light）：`relationship_text`——原本 note.md 唯一一段關係摘要全文
     （沒有逐季細分），從中萃取跟這個人「個人特質」相關的線索。
2. 用 Read 工具讀取該人現有的 `notes/<person_slug>/note.md`，找到
   `**一句話摘要**：` 那一行的位置。
3. 用 Edit 工具做兩處修改：
   a. 在 `**一句話摘要**：` 那一行**正下方**插入一行新的、格式完全相同的標記行
      （dashboard 會用同樣的 regex 慣例解析，務必逐字符合格式，不要加其他符號）：
      ```
      **人物側寫**：（單句，描述這個人整體是什麼樣的人，例如「務實內斂、重承諾，
      話題多圍繞工作與家庭，深夜也會回訊息」；不要跟一句話摘要重複——一句話摘要講
      的是「這段關係」，人物側寫講的是「這個人」）
      ```
   b. 在正文（`**關係總覽**：`／輕層唯一段落 之後、深層的逐季 `## YYYYQn` 區塊
      之前）插入一個新區塊：
      ```
      ## 人物側寫
      **性格特質**：（2-3 句，綜合 trait_observations／relationship_text 的性格
      線索，統整成連貫的描述，不要只是條列拼貼原句）
      **興趣主題**：（引用 top_keywords 裡真正像話題/興趣的詞彙佐證，剔除雜訊詞；
      若關鍵詞太零碎判斷不出明顯主題，誠實寫「樣本不足，看不出明顯主題傾向」）
      **溝通風格**：（引用 quant_summary 的數字佐證，例如「互動中對方主動開啟話題
      佔比較高（initiation_share_self偏低即對方主動較多）」「深夜訊息比例偏高，
      推測作息偏晚」「情緒詞出現頻率高/低」等，用白話轉譯數字，不要直接貼欄位名稱）
      **生活型態線索**：（若素材不足以支持某個面向，誠實寫「資料不足，無法判斷」，
      不要為了填滿欄位而過度推論）
      ```

## 原則

- 這是**彙整既有結論**，不是重新分析——`trait_observations`／`relationship_text`
  已經是先前逐行閱讀訊息後寫下的判斷，你的工作是統整成連貫的一段話，不要無中生有
  新增素材裡沒有的推論。
- 深層的人樣本通常較豐富，可以寫得具體；輕層的人樣本較少，內容平淡、量化訊號
  不明顯就如實寫「樣本有限」，不要硬掰性格描述。
- 這是私人真實對話的衍生分析，以中立、不帶評判的角度處理，不對這個人做道德評價。
- 只做上述兩處編輯，不要更動 note.md 其他既有內容（既有的逐季區塊、代表性片段
  等維持原樣）。
