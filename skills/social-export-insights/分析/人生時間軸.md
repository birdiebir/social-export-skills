# 人生事實表、人生時間軸與年度回顧（方法說明）

2026-10 新增。整理自一個兩帳號專案的實作：先做「人生事實表」，再做「人生時間軸＋年度回顧卡片」模組，最後做語意複查。程式和專案的頁面產生器、資料夾結構綁得很緊，所以這裡**只收方法和規格，沒有收程式範本**；引文驗證共用 `程式\共用\quotes_strict_template.py`。

以下例子都是虛構的。

## 1. 先做事實表，再做時間軸

- **事實表**（唯讀萃取）：從兩個帳號萃取可以查證的人生事實，範圍包括學校、居住地、旅行、工作、證照與比賽、社團、重要事件、帳號、興趣。每一筆都要有：
  - 編號
  - 事實（一句話）
  - 起訖時間（當地日期）
  - 帳號（哪份匯出＋發言者，或系統紀錄）
  - L1 出處（檔案＋seq）
  - 信心
  - 跟知識庫的比對：已有、缺少，或衝突
- **信心分三級**：
  - 確定：本人明說，或系統紀錄
  - 高：多處吻合
  - 推測：只有單一間接線索，例如只加入社團、只有登入 IP 位置
- **衝突另外列**：跟知識庫或既有勘誤不一致的事實，列在表頭的衝突區，不要自己裁決，等使用者確認。學校起訖年份這類容易錯、又會被大量引用的事實，確認之前一律不寫進新內容，派工的共同規則也不要沿用舊年份。
- 私訊如果是用關鍵字抽樣找的，表頭要寫明「不是全讀」。
- 事實表的副本跟時間軸放在一起，verify 時比對原檔和副本有沒有分歧。

## 2. 時間軸的收錄規則（寫進 notes 的 meta，產生器和 verify 都照做）

- 只收「確定」和「高」。同一列裡寫成推測的部分不收。衝突一律不收。
- **日期一律換成當地日期**：
  - 用一份居住時段表（places），把 L1 的匯出時區換成當地時間。
  - 居住時段要用登入國家逐日核對，再參考機場、航班相關訊息切開。真實案例：原本整段算在國外的時期，中間其實回國住了三個月；出國日也晚了幾天，因為出發前一天還在國內機場。
- **回報日不是發生日**：「跟媽媽說考過了」那天，不是考試那天。這類標題寫「自述」「跟某人說」，日期用回報日。
- **兩個帳號互傳的信件是草稿**：本人用新帳號傳給舊帳號的信，多半是擬稿或筆記。標題寫「擬好」，不寫「寄出」，除非另外有寄出的證據。
- **只有「加入／按讚」的**：標題寫「關注」「加入」，不寫「開始做」「重拾」「轉向」「鎖定」。
- **標題不能暗示沒有確認的事實**，例如「國中時期」配上未確認的年份。年齡要用出生年月實算。
- **裝置、帳號類事件**：用型號第一次出現在登入紀錄的日期，標題寫「首次出現在登入紀錄」，只寫紀錄裡的型號，不推論是誰操作的。
- **興趣年表的時間要用原始動作紀錄**，例如個人檔案的「新增了 X」、社團加入紀錄。按讚專頁的時間可能被平台重新標過，詳見 `social-export-analysis` 的 `references\pitfalls.md` §D2。
- **第三方**：只寫泛稱，不寫姓名、私事、電話、地址。伴侶、家人只放訊息數字。

## 3. 年度回顧卡片（程式從 L1 重算，不寫進 notes）

- **每年一張卡片**：亮點（從時間軸挑本人的事件，最好 3 件以上，不到 3 件就印 WARN）、幾個數字方塊、24 小時熱度條、最常用的表情前幾名。
- **口徑**（頁面「資料來源與方法」要照抄）：
  - 本人訊息只算「這個帳號自己的別名」在「自己那份匯出」裡的訊息，共同串因此不會重複算。
  - 只算實際打字或傳送的（`is_typed`：不含系統紀錄、群組事件、範本句），不含已收回的、整串 AI 對話（AI 資料夾和收件匣裡的都要排除），也不含被改歸 AI 的回答。
  - 小時要用當地時間算。
  - 數表情之前，先切掉心情回應尾巴；★☆ 這類文字符號不算。
  - 聊天對象只算人：排除交易、陌生訊息、AI 對話；當年雙方都有打字才算；兩份匯出同名的對話算同一位。

## 4. verify 要檢查的項目

1. 收錄規則：編號存在、信心是「確定／高」、不是衝突列。
2. 出處對回 L1：紀錄存在、「含」的字逐字在內、發言者對得上、當地日期落在事件起訖內（或標了事前／事後）。
3. 引文 strict（共用驗證器）。
4. 帳號口徑：訊息看發言者，系統紀錄看匯出。
5. 每個事件至少有一筆出處的日期落在起訖內（回溯事件例外）。
6. 年度亮點的年份落在事件起訖內，而且只放本人的事件。
7. 隱私：頁面文字不含第三方顯示名稱、電話、Email。

## 5. 一定要做語意複查

真實案例：時間軸第一版的事件錯了約三成，錯誤類型見 `查證與協作.md` §9。程式 verify 全過，還是錯這麼多。複查 agent 要：
- 逐事件回 L1 看前後文。
- 年度統計用獨立程式重算幾個年份。
- 居住時段用登入國家逐日核對。

複查發現的事實表錯誤，要同步更正事實表的原檔和副本，並留更正紀錄。
